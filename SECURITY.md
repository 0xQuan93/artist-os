# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not put
credentials, passcodes, exploit details, artist-private paths, or unreleased
media in a public issue.

Website mode must use HTTPS, a strong server-side passcode hash, persistent
storage, and a trusted reverse proxy. Keep ArtistOS bound to loopback unless the
deployment guide's proxy controls are in place. Never expose ACE-Step, Remotion,
or another native engine GUI directly.
