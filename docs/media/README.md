# Generated documentation media

These images and the animated GIF are deterministic outputs of the public
`tools/artistos-remotion/` pack. Rebuild them with:

```bash
cd tools/artistos-remotion
npm ci
npm run render:readme
```

Exact dimensions, render settings, status, and SHA-256 values are recorded in [`manifest.json`](manifest.json). They contain no private artist media or generated-model imagery. REGALIA//89
and related marks remain subject to [`TRADEMARKS.md`](../../TRADEMARKS.md).
